# MegaCraft Launcher (Android)

Неофициальный Android-лаунчер для установленного MegaCraft 0.3.0.

## Возможности
- Проверяет, установлен ли клиент MegaCraft (package: `com.lituty.megacraftpe`).
- Запускает установленный клиент.
- Сохраняет введённый ник локально на устройстве.
- Копирует `latecraft.ru` в буфер обмена.

> Лаунчер не содержит сам игровой клиент, не устанавливает и не изменяет его. Сначала установите MegaCraft отдельно. Адрес `latecraft.ru` найден в материалах клиента и не проверен как адрес игрового сервера.

## Сборка APK
Сборка запускается автоматически при push в `main` и вручную через GitHub Actions.

1. Откройте вкладку **Actions**.
2. Выберите workflow **Build Android APK**.
3. Нажмите **Run workflow**, если сборка ещё не запускалась.
4. После успешной сборки скачайте артефакт **MegaCraftLauncher-debug-apk** внизу страницы запуска workflow.

Для локальной сборки откройте репозиторий в Android Studio (JDK 17, Android SDK 35) и выполните задачу `assembleDebug`.
